# React Desafio Router

Projeto desenvolvido durante o curso de React da Origamid com o objetivo de praticar a criação de aplicações utilizando React Router e consolidar os principais conceitos do React.

## Objetivo

Construir uma aplicação com duas rotas: Produtos e Contato, a rota Produtos deve fazer uma busca na [API](https://ranekapi.origamid.dev/json/api/produto) e exibir esses produtos em sua rota. E a rota de contado exibe apenas informações de contato.

## Como executar

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/react-desafio-router.git
```

Entre na pasta:

```bash
cd react-desafio-router
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
